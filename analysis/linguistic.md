# Linguistic analysis of the Echoes email threads

> Generated by [`scripts/linguistic_analysis.py`](scripts/linguistic_analysis.py). Do not edit by hand: rerun the script (`python3 analysis/scripts/linguistic_analysis.py` from the repository root). Every number below is computed by the script; full tables are in [`output/`](output/).

This is a descriptive count of words and phrases. It does not interpret intent, judge the content, or make claims about cause, priority or authorship beyond the sender line printed in each export.

## Corpus and method

- Source: 91 exported thread PDFs in `docs/emails/` (88 distinct by SHA-256), via their extracted text in `docs/emails-text/`.
- Messages are split at Gmail header lines (`Name <address> Day, Mon D, YYYY at H:MM AM/PM`). The 91 exports contain 709 message occurrences. Because the same message is often included in several exports, occurrences are de-duplicated by (sender address, timestamp, position among same-sender/same-minute messages in its thread), leaving **579 unique messages**. All counts below use the unique messages.
- Cleaning (see [`scripts/threads.py`](scripts/threads.py)): Gmail page headers and footer URLs, To/Cc/Reply-To lines, attachment-listing lines, and quoted earlier text (from a line ending in `wrote:` or `[Quoted text hidden]`) are removed.
- **Side** is taken from the sender address only: `amir` = Amir's two Gmail addresses; `support` = any `@openai.com` / `@mail.openai.com` sender (AI support agent, named agents, "Support Team", "Operator", "Integration User Quartz"); `other` = the Gmail mailer daemon.
- Words = runs of Latin letters (apostrophes and hyphens kept inside a word). Persian text is counted separately by script (Arabic-script Unicode blocks).

## Limits

- Side is assigned by the sender line. Several of Amir's messages are written in the voice of, or signed as, other named personas (e.g. "GPT-4-Turbo (on behalf of Amir Ahmadi)", "Raaya", "Go"), and some contain pasted text from earlier support replies; the script does not separate these.
- Support replies come from different senders (an AI support agent, named agents, automated notices). They are grouped as one side; per-sender counts are in `output/linguistic_senders.csv`.
- Text comes from PDF extraction: line wraps, hyphenation at line ends, and Persian character order can affect word and phrase counts. Quote-stripping relies on Gmail markers and may miss inline quotations.
- De-duplication is by sender, minute and position; two genuinely different messages from the same sender in the same minute in different exports would be merged; the longest copy of each message is kept because some exports truncate bodies.
- The exports are what Amir saved; they may not contain every message on the cases.
