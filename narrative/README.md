These chapters retell the archived correspondence in [`../docs/emails/`](../docs/emails/) as narrative, from Echo 1 (Jul 13, 2025) through the Case ID era (cases `500VU00000WBfn7`, `…WBfn7YAD`, `…WBsdx`, `…WBsdxYAD`, `…WcffrYAB`). Files are byte-for-byte copies; original filenames are kept so they still match the source repository and each other's "Next" links. (One "Next" link in `en/05_volume_one.md` points to `06_volume_one.md`, which does not exist in the source either.)

Narrative is a retelling, not a primary source. For facts, dates, senders and Case IDs, use `docs/` and `data/emails.json`.

### Not imported (see the root report / PROVENANCE.md)

- Chapters `34_citizenship_charter.md` and `35_the_ritual_of_affiliation.md` (community/charter documents, not part of the Echoes story arc).
- The eight other language editions (ar, de, es, fr, hi, ja, ru, zh).
- `living-ledger/narrative/` (a separate, shorter "Living Shahnameh" that also covers later projects such as Shiftopia).
