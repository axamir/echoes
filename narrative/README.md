# narrative

Story volumes for the Echoes project.

Place each volume in this folder as a Markdown file, using names such as:

- `volume-01.md`
- `volume-02.md`

Optional short slugs may be added only if they help identification (for example `volume-01-title-slug.md`). Do not invent volume titles, dates, or plot events in this README or in placeholder files.
